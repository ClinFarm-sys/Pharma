⚙️ Configuración inicial de Firebase

Para usar FarmaSystem en la nube necesitas conectarlo a tu base de datos de Firebase. Sigue estos pasos una sola vez:

Paso 1:

Ve a console.firebase.google.com e inicia sesión con Gmail.

Paso 2:

Crea un proyecto nuevo → dale un nombre → desactiva Google Analytics → "Crear proyecto".

Paso 3:

En el proyecto, clic en el ícono Web (</>) → registra la app → copia la configuración que aparece.

Paso 4:

En el menú izquierdo: Build → Realtime Database → Crear base de datos → Modo de prueba → Listo.

Paso 5:

En Authentication → Sign-in method → Email/Password → Habilitar. Luego en Users → Add user: crea tu usuario admin.

Paso 6:

Pega aquí las credenciales que copiaste en el Paso 3:

Esta configuración se guarda en este dispositivo. Cada dispositivo nuevo debe ingresarla una sola vez.
